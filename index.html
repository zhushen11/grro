默认掩码显示。这类 publishable 密钥本身是公开的，锁保护的是「改配置」这个动作；请勿填 service_role 密钥。

建议设为 public；即使是私有桶，只要 anon 有 select 权限，签名直链依然可用。

APK 存进这个目录，留空则放桶根目录。中文名会转成 ASCII 键，原名记录在同目录 _manifest.json。

首次部署：三步
  1. 建桶：Storage → New bucket，名称与上面一致，勾选 Public。
  2. 开写权限：由于页面没有登录，需要给 anon 加 insert / select 策略，SQL 见下。
  3. 调上限：Storage → Settings 里把单文件上限调到装得下最大的包（免费版默认 50 MB）。
POLICY SQL 
-- 1. 建桶（已存在则跳过）
insert into storage.buckets (id, name, public)
values ('files','files',true)
on conflict (id) do nothing;

-- 2. 允许匿名读取（下载用）
drop policy if exists "apk_anon_select" on storage.objects;
create policy "apk_anon_select" on storage.objects
for select to anon
using (bucket_id = 'files');

-- 3. 允许匿名写入，仅限  目录
drop policy if exists "apk_anon_insert" on storage.objects;
create policy "apk_anon_insert" on storage.objects
for insert to anon
with check (
  bucket_id = 'files'
  and (storage.foldername(name))[1] = 'apk'
);
匿名写入意味着任何人都能上传、占满配额。对外长期使用建议改成登录后上传，或改用私有桶 + Edge Function 签发上传凭证。
